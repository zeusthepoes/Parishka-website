# Parishka Govender — refined website

## Files
- `index.html` — page content
- `style.css` — responsive layout and styling
- `script.js` — small-screen navigation

## Publish to GitHub Pages
1. Open the repository that publishes `https://zeusthepoes.github.io/`.
2. In the repository's **Code** tab, open the publishing root (normally the top level of the `main` branch).
3. Replace the existing `index.html`, `style.css` and `script.js` with these versions. Upload the files themselves, not the enclosing folder.
4. Commit the changes.
5. Check **Settings → Pages** to confirm the publishing source is still the intended branch and folder.
6. Open the site in a private browser tab after the Pages deployment completes.

The page uses Google Fonts and remotely hosted Unsplash photography, so those images and fonts require an internet connection. You can replace the image URLs in `index.html` with your own photographs at any time.
