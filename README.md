# Parishka Govender — Personal Website

A romantic, peony-inspired personal website with blush pink, ivory and champagne accents. The writing is intentionally gentle: it celebrates Parishka while leaving room for the possibility of shared experiences without assuming anything or applying pressure.

## Files
- `index.html` — website content and structure
- `style.css` — visual styling, responsive layout and floral imagery
- `script.js` — mobile navigation and current-year footer

## Preview locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts and externally hosted photographs.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `parishka-govender`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will provide the live website address after deployment.

## Personalise
- Replace the stock photos with your own photographs if you want to make the site more personal.
- Edit any wording in `index.html` so it sounds natural and true to you.
- The floral images currently use Pexels-hosted photographs; the other lifestyle images use Unsplash image URLs.
- If you add contact details later, use a contact method Parishka is comfortable with and keep it optional.

## Custom domain
If you own a domain, add it under **Settings → Pages → Custom domain** and configure the DNS records with your domain provider.
