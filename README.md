# Parishka Govender — Editorial Personal Website

A romantic, floral-inspired personal website with a more bespoke editorial layout: large calligraphy, blush pink peonies, ivory space, champagne details and a gentle "memory book" section.

The writing expresses thoughtful interest without assuming a relationship or putting pressure on Parishka.

## Files
- `index.html` — page content and structure
- `style.css` — editorial styling, peony imagery and responsive layout
- `script.js` — mobile navigation and footer year

## Preview
Open `index.html` in a browser. An internet connection is needed for Google Fonts and externally hosted photographs.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload these four files to the repository root, replacing the previous versions.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
5. Wait for GitHub Pages to publish the site.

## Before sharing
The photos are externally hosted sample images. Check that they load on your published site, and replace them with photos you have permission to use if you prefer. You can also edit the copy in `index.html` to make it sound more like you.
