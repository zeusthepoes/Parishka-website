# Parishka Govender website — reference-matched build

This package recreates the uploaded reference design as a responsive, working website using HTML, CSS and a small JavaScript file.

## Included files
- `index.html`
- `style.css`
- `script.js`
- `images/` (six locally stored image assets cropped from the supplied visual reference)

## Visual elements retained
- PG script monogram, full PARISHKA GOVENDER wordmark and desktop navigation
- Blush/ivory palette, wine-coloured typography and restrained gold rules
- Script “Parishka Govender” hero title and original tagline
- Pink peony hero, framed peony portrait and pink-peony footer photography
- “Life is made of little moments” introduction and original copy
- Quote band
- Three Memory Book cards: coffee, sunset and somewhere new
- Five “Things I Love” items
- Responsive mobile navigation and stacked mobile layout

The floral photographs included in the package are pink peonies only. No yellow-flower photograph or other flower variety is included.

## Publish to the existing GitHub repository
1. Open the `Parishka-website` repository.
2. Select the `main` branch and ensure you are viewing the repository root.
3. Upload/replace `index.html`, `style.css`, and `script.js` in the root.
4. Upload the entire `images` folder, keeping the six image files inside it.
5. Commit the changes.
6. Check **Settings → Pages**. For a project repository named `Parishka-website`, the project URL is normally `https://zeusthepoes.github.io/Parishka-website/` when Pages is published from `main` and `/(root)`.

Do not upload these files into an additional nested folder. `index.html` and `style.css` must sit next to one another in the repository root, with `images/` beside them.

## Notes
The photography is stored locally, so it does not depend on an external image host. Google Fonts are loaded online; the site has sensible serif and script fallbacks if Google Fonts are unavailable. The contact button opens an email draft addressed to no preset recipient because no email address was supplied.
