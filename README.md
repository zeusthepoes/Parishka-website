# Parishka Govender — Personal Website

A romantic, floral-inspired personal website with blush pink, ivory and champagne accents.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `parishka-govender`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will provide your website address after deployment.

## Personalise before publishing
- Replace the sample `hello@example.com` email link in `index.html` with the email address you want visitors to use.
- Replace the sample gallery photos with your own images if desired.
- Edit the About Me and favourite-things text to reflect your personality.
- The fonts and sample photography load from Google Fonts and Unsplash, so an internet connection is needed for those assets.

## Custom domain
If you want to use a domain you own, add it under **Settings → Pages → Custom domain** and configure the DNS records with your domain provider.
